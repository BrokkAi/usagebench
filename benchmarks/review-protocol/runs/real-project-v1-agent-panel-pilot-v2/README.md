# Rejected per-case prompt dry run

This directory preserves an incomplete dry run of the rejected v2 per-case
prompt. The prompt did not explicitly exclude the selected declaration token
from the usage set, and reviewers interpreted that boundary differently.

Only three OpenAI responses were completed before the protocol defect was
identified. No Anthropic responses or comparison were retained, and none of
these artifacts qualify as review evidence. The corrected, retained protocol
and complete experiment are in `../real-project-v1-agent-panel-pilot-v3/`.
